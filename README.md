# Venezuelan Livestock Market Explorer

A self-contained, responsive English-language research explorer for the Venezuelan livestock and agricultural market.

## Included

- FAOSTAT 2023 production indicators with 2024 estimated/imputed caveats
- Production geography and regional filters
- Value-chain explorer
- Actor map
- Regulatory timeline
- Source notes and evidence-confidence labels
- Light/dark mode
- No external runtime dependencies

Research cutoff: 3 August 2026.
